LINQ live coding, dạng bài anh Hiếu gửi

13 bài biến đổi dữ liệu bằng LINQ trong một file Program.cs. Viết code vào các hàm “// Code here”, bấm Run, mỗi bài tự in Correct hoặc Incorrect bằng cách so MD5 của JSON kết quả. Bài 1 đến 3 là đúng đề demo, bài 4 đến 12 là bài mới cùng kiểu, dữ liệu kiểu sổ cái tài chính.

Cách luyện

  1. Bấm Copy file luyện tập, mở .NET Fiddle, chọn Compiler .NET 8 (Project type: Console), dán đè toàn bộ code.
  2. Đặt giờ 5–8 phút mỗi bài, vừa gõ vừa nói to bằng tiếng Anh mình đang làm gì: “I group by account number, then project each group…”
  3. Run. Sai thì so phần JSON in ra với dòng // Expected ngay trên mỗi bài.
  4. Xong mới mở lời giải bên dưới để so cách viết.

Bẫy hay gặp ở dạng bài này

  • Thứ tự property quyết định JSON: anonymous type phải khai báo đúng thứ tự như Expected.
  • Thứ tự phần tử: GroupBy giữ thứ tự xuất hiện đầu tiên; đề nào ghi “ordered by” thì phải OrderBy, và thêm ThenBy để ổn định.
  • Kiểu List<object>: nhớ ép (object)new { … } hoặc .Cast<object>().
  • Tiền: đề demo dùng double, bài 4–12 dùng decimal. Khi nói thì nhấn mạnh: “in real code I'd use decimal for money”.
  • Hiệu năng: ToList một lần ở cuối; tránh duyệt lại cùng IEnumerable nhiều lần; GroupBy trên IQueryable của EF sẽ chạy ở database.
